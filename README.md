# ECU-stuff

A cleaner VAG diagnostics app, built for an ELM327 adapter running the Deep OBD replacement firmware.
The adapter does the timing-critical K-Line / CAN work; this project talks to it and presents the results.

## Status

| Step | What | State |
|---|---|---|
| 1 | `vagdata`: read the label files Deep OBD downloads | done |
| 2 | Adapter telegram layer, tested by replaying recorded `ifh.trc` traces | not started |
| 3 | KWP2000 / TP2.0 fault codes and live data, then the UI | not started |

## `vagdata` module

A pure JVM Kotlin library (no Android APIs, so the future Android app can use it as-is).

- `EncryptedZip` – minimal zip reader with ZipCrypto and inflate, no third-party dependencies
- `LabelFileReader` – password derivation and text decoding for `.ldat` / `.cdat` / `.uds`
- `CodeTable` – `codes.cdat`
- `LabelFile` – typed `.ldat` records (measuring blocks, adaptation, long coding, redirects …)
- `LabelResolver` – part number + diagnostic address → label file
- `UdsFile` – `.uds` segment container (column meanings come later)
- `VagDataDir` – ties it together for one language directory

The formats are described in [`docs/vag-data-formats.md`](docs/vag-data-formats.md).

```kotlin
val data = VagDataDir(File("/sdcard/ecu/Vag/en"))
val codes = data.loadCodes()
val labels = data.resolveLabelFile(LabelQuery(partNumber = "1K0035274B", address = 0x37))
labels?.longCoding()?.forEach { println("${it.byteIndex}: ${it.text}") }
```

## Build and test

```
./gradlew :vagdata:test
```

Needs JDK 17+. The unit tests use small invented fixtures in `vagdata/src/test/resources`, generated by
`scripts/make-test-fixtures.sh` with Info-ZIP's `zip`, an implementation independent of the Kotlin code.

To check the decoder against your own downloaded data (skipped when the variable is unset):

```
ECU_VAG_DIR=/path/to/Vag/en ./gradlew :vagdata:cleanTest :vagdata:test --tests '*RealDataTest*' -i
```

## Third-party data

The label files are Ross-Tech VCDS label files and VW-group data repackaged by Deep OBD. They are **not** part of
this repository and must not be committed: `.gitignore` excludes `data/` and `*.ldat`, `*.cdat`, `*.uds`, `*.enc0`
(except under `vagdata/src/test`). The planned app imports them from a folder chosen by the user.
